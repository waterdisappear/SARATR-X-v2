# README EN/ZH Split Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split every bilingual README into English-only `README.md` + Chinese-only `README_zh.md` with a mutual top-of-page language switcher.

**Architecture:** Manual content split from existing bilingual text (no machine translation of new claims). Shared HTML switcher snippet on every file. Cross-directory links point to the same-language README. Verify with repo-wide greps that bilingual markers are gone and both files exist in all 10 locations.

**Tech Stack:** GitHub-flavored Markdown / HTML snippets only (no JS, no docs site).

**Spec:** `docs/superpowers/specs/2026-08-15-readme-i18n-design.md`

## Global Constraints

- Default: `README.md` = English; `README_zh.md` = Chinese
- Switcher: current language bold plain text; other language relative link
- Figure captions: one language only per file
- Code/commands/paths/dataset names/model names identical across languages (comments may localize)
- Do not invent new technical claims; extract from existing bilingual text
- Do not change code, configs, weights, or figure assets
- Scope: exactly the 10 README locations listed below

### Shared switcher (copy exactly)

English file top (after centered hero on root; otherwise first block):

```html
<p align="right">
  <b>English</b> | <a href="./README_zh.md">中文</a>
</p>
```

Chinese file top:

```html
<p align="right">
  <a href="./README.md">English</a> | <b>中文</b>
</p>
```

### Shared split algorithm (apply on every task)

1. Headings `## Foo / 中文` → EN `## Foo`; ZH `## 中文` (choose natural Chinese title already present).
2. Blocks marked `**EN** —` / `**中文** —` → keep only the matching language; drop the marker.
3. Parallel English then Chinese paragraphs → keep only matching language.
4. Inline `English / 中文` or `term / 术语` in prose/lists/tables → keep only matching side; keep code identifiers unchanged.
5. Directory-tree comments `# English / 中文` → EN `# English`; ZH `# 中文`.
6. Figure HTML captions: keep only the `Fig. N | ...` block in EN; only the `图 N | ...` block in ZH.
7. Links to other READMEs: EN → `.../README.md`; ZH → `.../README_zh.md`.
8. Author line (root): EN = English names only; ZH = Chinese names only (order preserved).
9. TOC anchors must match the language-specific heading ids.

### Shared verification command (run at end of every task)

From repo root, for directory `$DIR` (use `.` for root):

```powershell
$dir = "<DIR>"   # e.g. "." or "pre-training"
$en = Join-Path $dir "README.md"
$zh = Join-Path $dir "README_zh.md"
Test-Path $en; Test-Path $zh
Select-String -Path $en,$zh -Pattern '\*\*EN\*\*|\*\*中文\*\*| / 简介| / 预训练| / 分类| / 检测| / 分割| / 声明|Fig\. \d+ \|[\s\S]*图 \d+ \|' -SimpleMatch:$false
Select-String -Path $en -Pattern 'README_zh\.md' | Select-Object -First 1
Select-String -Path $zh -Pattern '\]\(\./README\.md\)|href="\./README\.md"' | Select-Object -First 1
```

Expected:

- Both `Test-Path` → `True`
- Bilingual-marker `Select-String` → no hits (empty)
- EN file contains link to `README_zh.md`
- ZH file contains link to `./README.md`

Also manually confirm section headings in EN and ZH cover the same topics (structure parity).
